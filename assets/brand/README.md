Visual identity assets for `Wol-rust-docs-pp-cli`, generated with Grok from project-specific art-direction prompts.

| File | Purpose | Dimensions |
|---|---|---|
| `profile.jpg` | Square profile/avatar image | 1024×1024 |
| `mascot.jpg` | Main mascot | 784×1168 |
| `mascot-tall.jpg` | Vertical mascot | 784×1168 |
| `social-preview.jpg` | GitHub social preview and README banner | 1280×640 |

## Set the GitHub social preview

GitHub currently requires this upload through the web interface:

1. Open the repository's **Settings**.
2. Under **General**, find **Social preview** and click **Edit**.
3. Click **Upload an image** and select `assets/brand/social-preview.jpg`.
4. Save the setting.

The file is a JPG under 1 MB at the 1280×640 size recommended by [GitHub's social-preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
